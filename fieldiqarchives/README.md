# Interface FieldIQ

A aplicação usa uma API autenticada e PostgreSQL persistente.

Execute `npm install` e `npm start` na raiz do repositório, um nível acima desta pasta.
Abrir somente `public/index.html` não inicia o banco nem o servidor.

Veja o [README principal](../README.md), o [esquema PostgreSQL](../database/001-schema.sql) e o [roteiro do TCC](../docs/APRESENTACAO-TCC.md).

Na Vercel, selecione a raiz do repositório. O exemplo Python e o SQL antigo foram substituídos pelo servidor Node e pelo esquema em `database/`.
